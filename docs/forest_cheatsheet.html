Play the 3D Data Forest with your eyes

Collect the glowing data orbs in a 3D forest by looking at them. Here's how to start it, play it, and fix anything that feels off.

What it is

A 3D forest where 8 glowing orbs (the flood data sources) float around a character. You collect an orb by looking at it and holding still for about a second. Collect all 8 to complete the dataset. Same eye-tracking as the 2D game.

Start it up — needs BOTH servers running

1

Start the eye tracker

Open a PowerShell window and paste this. Leave it open.

cd "C:\game integration\gaze-detection"
.\gaze_env\Scripts\python.exe gaze_server.py
2

Start the game server

Open a second PowerShell window, paste this, then open http://localhost:8000/forest.html in your browser.

cd "C:\game integration\game\workingGameTemplate"
python -m http.server 8000

Why two servers? The 3D game must be served over http:// (it won't run by double-clicking the file). The eye tracker is the same program from the 2D game.

How to play

1
Look at a glowing orb. It brightens, grows, and its label lights up.
2
Hold your gaze ~1 second. The ring fills, the orb pops with particles + a sound, and the archer reacts. Your counter goes up.
3
Drag with the mouse to orbit and find orbs hidden behind the character.
4
Collect all 8 → a win screen appears. Look-and-hold "Train the Model", then "Play Again" — no mouse needed on the win screen.

Controls

look + hold ~1s
Collects the orb you're looking at (or clicks a win-screen button).
F
Fullscreen on / off (and enables sound).
C
Recenter — press whenever the cursor feels shifted.
G
Turn gaze control off / on.
mouse drag
Orbit the camera to look around.

If something feels wrong

Nothing loads / blank page
Make sure the game server (step 2) is running, and you opened http://localhost:8000/forest.html — not the file directly.
Cursor is in the wrong place
Press F for fullscreen, then C and look at the yellow target.
Orbs are hard to select
Recenter again (C), and orbit an orb toward the middle of the screen — gaze is sharpest at center.
No cursor / "face —"
Check the eye-tracker window (step 1) is running; the bottom-left label should show face: yes.
No sound
Press any key (e.g. F) once — browsers only allow sound after a key-press.
When finished, press Ctrl + C in both PowerShell windows to stop the servers (frees the webcam and the port).
